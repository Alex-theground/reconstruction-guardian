# 새 대화에서 이어가기 위한 요약

새 창에 이 파일 내용과 dev-map.zip을 함께 붙여 넣고 "이어서 진행해줘"라고 하면 됩니다.

## 목표
서울시·국토부 개발정보를 모아 지도에 개발예정구역을 표시하고, 개발 후 건물 모습을 가상으로 보여주는 웹페이지.
